\# Movie Recommendation System



A Movie Recommendation System built using Python, Pandas, Streamlit, and the TMDB 5000 Movies Dataset.



\## Features

\- Recommend similar movies

\- Content-based filtering

\- Interactive Streamlit UI



\## Technologies Used

\- Python

\- Pandas

\- Streamlit

\- Scikit-learn



\## Dataset



This project uses:

\- tmdb\_5000\_movies.csv

\- tmdb\_5000\_credits.csv



The datasets are not included in this repository because of file size limitations.



Download the dataset from Kaggle:

https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata



Place both CSV files in the project folder before running the app.



\## Run Locally



```bash

pip install -r requirements.txt

streamlit run app.py
